ADDING YOUR OWN TOPX DATA SOURCES
=================================

As of TopX 1.2 you no longer edit any PHP files to add a Data Source. Everything
is managed from:

    Console -> Management -> TopX Data Sources

The list shows every Cacti Data Template, whether or not TopX already ranks it.
Use the filter bar (Search, Supported: All / Yes / No, Rows) to narrow it down,
exactly like Cacti's CDEF, Data Query and other management pages. The "In Use"
column shows how many Data Sources on your devices use each template, so you can
tell in-use templates from unused ones at a glance.

Click a row (or the "Add" link) to open the editor, fill in the fields below and
save. Clicking a template whose Supported column shows "No" opens the editor
already pointed at that template, so turning it into a supported source only
takes a couple of clicks. Use Import / Export to move definitions between
installs - the export is an XML document keyed on the Data Template hash, so it
applies cleanly to any Cacti that has the same template.


ONE DATA SOURCE OR SEVERAL?
---------------------------

A Data Template often defines more than one RRD data source (for example an
interface template has traffic_in and traffic_out).

  * If you only care about ONE of them, create a single definition and name that
    field in the Metric Expression, e.g. "traffic_in=traffic_in". You do NOT
    need multiple rows for this.

  * If you want to rank SEVERAL of a template's fields SEPARATELY (e.g. a Top-N
    of inbound traffic AND a separate Top-N of outbound traffic), add one
    definition per field - multiple rows for the same Data Template are allowed.
    Each definition becomes its own entry in the dashboard's data source picker.

  * If you want to rank by a COMBINATION (sum, percentage, ...), use one
    definition with a combining Metric Expression, e.g. "traffic_in+traffic_out"
    or "hdd_total%hdd_used".

The bundled defaults are seeded against the standard Cacti package template
hashes. If your install uses a template with a different hash (a custom or
repackaged template), the seeded row will show as "(template not installed)" and
your real template will show as "Supported: No" - just click it and configure a
definition. This is why a template may not appear "auto-supported": the support
is keyed on the exact template hash.


EDITOR FIELDS
-------------

Data Template      The Cacti Data Template this definition ranks. The portable
                   template hash is stored, so the definition survives
                   export/import between installs.

Display Name       Friendly name shown on the dashboards. Blank = template name.

Metric Expression  How the RRD data source fields are combined:
                     single field    cpu=cpu
                     sum             traffic_in+traffic_out
                     percentage      hdd_total%hdd_used
                     scaled          uptime/100

Metric Label       Short label for what is measured (e.g. "Utilization",
                   "Bits"); used on the chart value axis.

Range Direction    Increasing - higher is more significant (CPU, traffic), or
                   Decreasing - lower is more significant (free disk space,
                   uptime headroom). Drives the default ranking sense and the
                   threshold colouring.

Default Sort       Default sort direction when the source is first opened.

Display Scaling    Strip  = round to the precision and append the unit.
                   Divide = walk a slash-delimited unit/divisor ladder
                            (e.g. bit/Kbit/Mbit).

Display Unit(s)    The display unit, or a slash-delimited ladder for Divide
                   scaling (e.g. "bit/Kbit/Mbit/Gbit").

Precision /        Strip  = number of decimal places.
Divisors           Divide = slash-delimited divisor ladder
                            (e.g. "1/1024/1048576").

Value System       Numbering system used when auto-scaling unsupported values.

Normal / Warning / Optional absolute health thresholds. Leave blank to disable
Alert Threshold    threshold colouring. For an Increasing range a value at or
                   above a threshold is in that band; for a Decreasing range a
                   value at or below a threshold is in that band. These are an
                   absolute health signal and are independent of the dashboard's
                   "Values by % of Peak" card, which is always relative to the
                   live peak of the returned set.

Chart Label        How each ranked item is named on the chart, using |token|
Pattern            substitution:
                     |host_description|  |host_hostname|  |host_id|
                     |query_<field>|     e.g. |query_ifName|, |query_hrStorageDescr|
                   Example: "|host_description| - |query_ifName|". Unresolved
                   tokens are dropped and the separators tidied, so the pattern
                   degrades cleanly. Blank = derive the label from the Data
                   Source name.
